# Momo Store Backend

Docker-образ для API сервиса на языке Golang.

## Сборка образа

```bash
docker build -t momo-backend:latest .
```

При указании целевой архитектуры (по умолчанию `linux/amd64`):

```bash
docker build --build-arg TARGETARCH=arm64 -t momo-backend:arm64 .
```

## Запуск контейнера

```bash
docker run -d -p 8081:8081 --name momo-api momo-backend:latest
```

После запуска health-check доступен по адресу:
```
http://localhost:8081/health
```

## Использованные технологические решения

- Для сборки используется официальный образ `golang:1.26-alpine` со всеми инструментами для компиляции.
- Финальный образ основан на `alpine:3.22.4` и содержит только скомпилированный бинарный файл и минимальные зависимости необходимые для работы.
- Итоговый образ не содержит компилятор, исходный код или пакетный менеджер.
- В финальный образ добавлены `wget` (для health-check) и корневые SSL-сертификаты для исходящих HTTPS-соединений.
- Приложение запускается от непривилегированного пользователя `appuser`. 
- Используется статическая линковка `CGO_ENABLED=0` для отсутствия зависимостей от системных библиотек.
- Дополнительные флаги линковки `-ldflags="-w -s"` для исключения отладочной информации.
